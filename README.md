# LibroCalificacionesPromedioClase

Proyecto desarrollado en **C#** como parte de las prácticas de programación para trabajar con el cálculo del promedio de calificaciones de una clase.

## Contenido del proyecto

El repositorio contiene dos aplicaciones que presentan diferentes formas de calcular el promedio de las calificaciones.

### 1. Promedio de clase con valores enteros LibroCalificacionesPromedioClase

Esta aplicación permite ingresar una cantidad determinada de calificaciones y calcular el promedio de la clase.

El resultado del promedio se maneja utilizando valores enteros.

### 2. Promedio de clase con centinela LibroCalificacionesPromedioClase2

Esta aplicación utiliza una estructura de repetición controlada por centinela (-1) , permitiendo ingresar calificaciones hasta que el usuario introduzca el valor establecido para finalizar la entrada de datos.

En esta versión, el promedio se calcula utilizando un valor decimal, permitiendo obtener un resultado más preciso.
